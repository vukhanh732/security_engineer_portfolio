BrainTrain

A complete brain-training product with six playable games, persistent progression, rankings, streaks, and detailed insights running against a live Supabase backend.

SCOPE

I wanted to build a product with enough connected state to expose real engineering decisions: authenticated users, game sessions, adaptive difficulty, rankings, streak recovery, leaderboards, and analytics that all need to agree.

APPROACH

Next.js renders the application and Supabase owns authentication and persistence. Every completed round passes through one session-recording path, which updates personal bests, adaptive difficulty, streak state, Brain Score, and Brain Elo without duplicating that logic across games.

WHAT I BUILT
  • Six distinct games covering mental maths, memory, focus, abstract reasoning, reaction time, and typing
  • Cross-session adaptive difficulty with explicit player-controlled tiers
  • A ten-tier Brain Elo system whose history can be reconstructed from session events
  • Streaks with weekly freeze recovery, opt-in leaderboards, and per-game insights
  • Pure, unit-tested scoring and analytics modules plus end-to-end verification against a real Supabase project
ENGINEERING DECISION

Elo is treated as an accumulated event history rather than a value that can be safely recalculated from current stats. The insights engine replays chronological sessions to rebuild that history, while Brain Score remains a live normalized snapshot across games.

OUTCOME

BrainTrain is deployed at braintrain.space as a working product, not a static demonstration. Users can create an account, play every game, build a streak, move through ranked tiers, and inspect their own performance trends.
