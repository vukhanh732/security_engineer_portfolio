Poly Haven's [license statement](https://polyhaven.com/license) covers downloaded assets under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Individual model authors, original download URLs and hashes are recorded in `assets/study/provenance.json`; the hashes describe original source downloads, before JPEG optimization. Texture dimensions are capped at 1024px and JPEGs are optimized locally. The asset license record is `assets/study/LICENSE.txt`.

The loading/sharing image is captured from the actual new room. The slow clear-to-overcast lighting is artistic, with no live weather service. Optional rain is not included.

The retro desktop is an original 1990s-inspired interface, not an official Microsoft product. No Henry Heffernan or Bruno Simon models, artwork, branding or source code were copied.
